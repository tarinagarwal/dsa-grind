# DSA Learning Plan

## Phase 1: C++ Fundamentals

- Variables, data types, operators
- Conditionals (if-else, switch)
- Loops (for, while, do-while)
- Functions and recursion basics
- Arrays and strings
- Pointers and references

## Phase 2: STL (Standard Template Library)

- Vectors, pairs, iterators
- Sets and maps (ordered + unordered)
- Stacks, queues, deques
- Priority queues
- Sorting and searching with STL
- Useful functions (sort, reverse, lower_bound, upper_bound, etc.)

## Phase 3: Basic Problem Solving

- Pattern printing problems
- Basic math problems (GCD, LCM, prime numbers, factorials)
- Number theory basics

## Phase 4: Bit Manipulation

- Binary representation
- Bitwise operators (AND, OR, XOR, NOT, shifts)
- Common tricks (check if power of 2, count set bits, etc.)
- Classic bit manipulation problems

## Phase 5: Recursion & Backtracking

- Recursion fundamentals
- Recursion on arrays and strings
- Backtracking (subsets, permutations, N-Queens, Sudoku)

## Phase 6: Sorting & Searching

- Bubble, selection, insertion sort
- Merge sort, quick sort
- Binary search and its variations
- Two pointer technique
- Sliding window

## Phase 7: Linked Lists

- Singly linked list
- Doubly linked list
- Circular linked list
- Classic problems (reverse, detect cycle, merge, etc.)

## Phase 8: Stacks & Queues

- Implementation and operations
- Monotonic stack/queue
- Classic problems (next greater element, valid parentheses, etc.)

## Phase 9: Trees

- Binary trees (traversals, height, diameter)
- Binary search trees
- AVL trees basics
- Segment trees and Fenwick trees (later stage)

## Phase 10: Heaps

- Min heap, max heap
- Heap operations
- Priority queue problems
- Top K problems

## Phase 11: Graphs

- Representation (adjacency list/matrix)
- BFS and DFS
- Cycle detection
- Topological sort
- Shortest path (Dijkstra, Bellman-Ford)
- MST (Prim's, Kruskal's)
- Union-Find (DSU)

## Phase 12: Dynamic Programming

- 1D DP (fibonacci, climbing stairs)
- 2D DP (grid problems, LCS, LIS)
- DP on strings
- DP on trees
- Knapsack variations
- Partition problems

## Phase 13: Advanced Topics (Optional)

- Tries
- Segment trees with lazy propagation
- Heavy-light decomposition
- String algorithms (KMP, Rabin-Karp, Z-algorithm)
